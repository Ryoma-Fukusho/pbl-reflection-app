Claude API 利用費について（PBL振り返り支援システム）

卒業研究　2026年8月18日

1. 使用目的

  • システムの AI 対話部分を現在の Gemini API から Claude API に変更し、学生に投げかける問いの品質を安定させるため
  • 主な用途は開発・デバッグとプロンプト設計
  • 9月上旬の予備実験（5〜10名）と、12月前後の本実験（20〜30名）でも使用

2. 使用モデル

  • 主に Claude Sonnet 5 を使用（100万トークンあたり 入力 $3 / 出力 $15）
  • 応答品質の比較確認のため Claude Opus 5 も一部使用（同 入力 $5 / 出力 $25）
  • 料金表：https://platform.claude.com/docs/ja/about-claude/pricing

3. 月々の費用の目安

学生1人が振り返りを1回通しで行うと、約30円かかります。これを基準に月別で試算しました。

月 主な作業 費用の目安
2026年8月 Claude API への差し替え・動作確認 約 3,500円
9月 予備実験と直前の調整 約 5,600円
10月 予備実験の結果を受けたプロンプト再設計 約 10,500円
11月 本実験に向けた最終調整 約 7,000円
12月 本実験 約 3,200円
2027年1月 追加検証・再実行 約 2,800円
6か月の合計 約 36,000円
  • ご相談したい申請額は 月額上限 12,000円（6か月で 60,000円） です
  • 試算との差額は、為替の変動やプロンプト調整の試行回数が想定を超えた場合に備えた余裕分です

4. 補足

  • 金額は 1ドル＝160円で換算しています（実勢より円安寄りに置いています）
  • Anthropic の管理画面で月の利用上限を設定できるため、申請額を超える請求は発生しません
  • 利用明細はモデルごとに分かれて記載されるため、使用モデルは上記2つに固定します
  • 現時点では、学生に継続的に使用させて経過を追う設計にはしていません。実施する場合は1クラス30名・週1回・3か月で月4,000円程度の増加になります
  • トークン数は多めに見積もった概算です。システム側で実際の使用量を記録しているため、予備実験後に実測値で見直せます
